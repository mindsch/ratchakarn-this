## 1. Thai official document system

Governing rule: ระเบียบสำนักนายกรัฐมนตรีว่าด้วยงานสารบรรณ พ.ศ. 2526, amended 2548 (e-สารบรรณ), 2560, 2564. [verified, names only]

### The 6 หนังสือราชการ types [verified]
| # | Type | Paper | Notes |
|---|---|---|---|
| 1 | หนังสือภายนอก | กระดาษตราครุฑ | formal, between agencies or to outsiders, has คำลงท้าย |
| 2 | หนังสือภายใน (บันทึกข้อความ) | กระดาษบันทึกข้อความ | less formal, within a ministry/department/province, no คำลงท้าย |
| 3 | หนังสือประทับตรา | ครุฑ | stamp replaces signature, only 6 low-stakes cases (ขอรายละเอียด, ส่งสำเนา, ตอบรับทราบ, แจ้งผลงาน, เตือนเรื่องค้าง, ที่สั่งให้ใช้) |
| 4 | หนังสือสั่งการ | ครุฑ | คำสั่ง / ระเบียบ / ข้อบังคับ |
| 5 | หนังสือประชาสัมพันธ์ | ครุฑ (ข่าว = bond paper) | ประกาศ / แถลงการณ์ / ข่าว |
| 6 | หนังสือที่เจ้าหน้าที่ทำขึ้นหรือรับไว้เป็นหลักฐาน | varies | หนังสือรับรอง, รายงานการประชุม, บันทึก, หนังสืออื่น (includes คำร้อง from the public) |

Structure of every letter: หัวเรื่อง, เนื้อเรื่อง (ภาคเหตุ / ภาคความประสงค์ / ภาคสรุป), ท้ายเรื่อง (คำลงท้าย, ลายมือชื่อ, ส่วนราชการเจ้าของเรื่อง).

Urgency (ชั้นความเร็ว): ด่วนที่สุด / ด่วนมาก / ด่วน, red text 32pt. Secrecy: ลับที่สุด / ลับมาก / ลับ. [verified]

บันทึกความเห็น structure: ปัญหา, ข้อเท็จจริง, ข้อพิจารณา, ข้อเสนอ. [verified]

### Writing rules usable as prompt content [verified, from reference 4 below]
- เรื่อง: shortest, a phrase or sentence, searchable, distinguishable ("ขอความร่วมมือในการจัดสัมมนานักบริหาร" not "ขอความร่วมมือ"). Reply letters reuse the original เรื่อง, often prefixed "การ".
- Opening words: ด้วย (unprompted background), เนื่องจาก (firm reason), ตาม/ตามที่/อนุสนธิ (prior contact; ends with "นั้น").
- Closing by purpose:
  - แจ้ง: จึงเรียนมาเพื่อทราบ
  - ชี้แจง: จึงเรียนมาเพื่อโปรดทราบ
  - สั่งการ: จึงเรียนมาเพื่อถือเป็นหลักปฏิบัติต่อไป
  - ขออนุมัติ: จึงเรียนมาเพื่อโปรดพิจารณาอนุมัติด้วย จะขอบคุณมาก
  - ขอความร่วมมือ: จึงเรียนมาเพื่อขอได้โปรดให้ความร่วมมือ ... ขอบคุณมาก
  - เตือน / กำชับ / ถาม / หารือ each have their own closer.
- Pronouns: agency uses its own name or omits; person uses ข้าพเจ้า/กระผม/ดิฉัน; addressee person = ท่าน, agency = ชื่อหน่วยงาน.
- Word-strength ladder: ควร < พึง < ย่อม < ต้อง/ให้; จะ vs จัก; ขอให้ (command) vs โปรด (request).
- Avoid doubled connectors (ที่-ซึ่ง-อัน), spoken register, foreign words, destructive words (prefer constructive phrasing).
- Letter-purpose recipes (ครวญ-ออด-มัด for cooperation; ครวญ-ยอ-ล่อ-ออด-มัด for help requests). Includes ปฏิเสธ (thank, reason, hope for later; no apology when refusing a statutory request), ตักเตือน (redirect, don't blame directly), เชิญ, ขอบคุณ, นำส่ง, สอบถาม, ตอบ. Gold for a "doc type" skill library.

## 3. BYOK web architecture

- Vercel AI SDK: provider-neutral, OpenAI provider accepts `baseURL`, so any OpenAI-compatible endpoint (ThaiLLM, Typhoon API, OpenRouter, Ollama, vLLM) works with one adapter.
- Browser-direct calls need CORS support from the provider. A stateless pass-through proxy is the fallback (must not log keys).
- MCP in browser: stdio servers cannot run; remote Streamable HTTP/SSE servers can, if they allow CORS. Proxy otherwise.
- Keys: sessionStorage by default, localStorage opt-in, never sent to our server except via the pass-through.
