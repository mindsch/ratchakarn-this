# ชนิดเอกสารอื่น: บันทึกข้อความ คำร้อง หนังสือรับรอง คำสั่ง ประกาศ

## บันทึกข้อความ — `ชนิด: บันทึกข้อความ`
หนังสือภายใน ใช้ภายในกระทรวง ทบวง กรม หรือจังหวัดเดียวกัน ไม่มีคำลงท้ายและไม่มี "ขอแสดงความนับถือ" หัวกระดาษมี ส่วนราชการ / ที่ / วันที่ / เรื่อง / เรียน
- บันทึกเสนอ/รายงาน: เสนอผู้บังคับบัญชา สั้นกระชับ
- **บันทึกความเห็น** ใช้โครง: 1. ปัญหา (สาเหตุสั้นๆ) 2. ข้อเท็จจริง (หลักฐานข้อมูล) 3. ข้อพิจารณา (วิเคราะห์) 4. ข้อเสนอ (สิ่งที่เสนอให้สั่งการ)
- บันทึกสั่งการ: ผู้บังคับบัญชาสั่งผู้ใต้บังคับบัญชา
ปิดท้ายตามวัตถุประสงค์ เช่น "จึงเรียนมาเพื่อโปรดทราบ" "จึงเรียนมาเพื่อโปรดพิจารณา" แล้วลงชื่อและตำแหน่ง

## คำร้อง (จากประชาชนถึงหน่วยงาน) — `ชนิด: คำร้อง`
ใช้เมื่อประชาชนยื่นคำขอหรือเรื่องถึงหน่วยงานรัฐ โครง: สถานที่/วันที่ → เรื่อง → เรียน → ข้าพเจ้า [ชื่อ อายุ ที่อยู่ เลขบัตรประชาชน (ถ้าจำเป็น) โทรศัพท์] → ข้อเท็จจริงเรียงเป็นข้อ → สิ่งที่ขอ → "จึงเรียนมาเพื่อโปรดพิจารณา" → ขอแสดงความนับถือ → ลงชื่อ → เอกสารแนบ หลักฐานให้ระบุเป็นรายการ

## หนังสือรับรอง — `ชนิด: หนังสือรับรอง`
ส่วนราชการออกให้เพื่อรับรองบุคคลหรือหน่วยงาน ไม่ระบุผู้รับ โครง: ชื่อ "หนังสือรับรอง" → ที่ → ข้อความรับรอง "หนังสือรับรองฉบับนี้ให้ไว้เพื่อรับรองว่า [ชื่อ] ... [ข้อเท็จจริง] ..." → "ให้ไว้ ณ วันที่ ..." → ลงชื่อ ตำแหน่ง ถ้าเป็นเรื่องสำคัญที่ออกให้บุคคล ต้องติดรูปถ่าย (แจ้งผู้ใช้)

## คำสั่ง — `ชนิด: คำสั่ง`
โครง: "คำสั่ง [หน่วยงาน]" → ที่ ... /ปี → เรื่อง → ข้อความ: อ้างเหตุที่ออกคำสั่ง → อ้างอำนาจตามกฎหมาย (เฉพาะที่ผู้ใช้ให้) → ข้อความที่สั่งเป็นข้อๆ → "ทั้งนี้ ตั้งแต่วันที่ ... เป็นต้นไป" → "สั่ง ณ วันที่ ..." → ลงชื่อ ตำแหน่ง ใช้ถ้อยคำบังคับ "ให้ ..." "ต้อง ..."

## ประกาศ — `ชนิด: ประกาศ`
โครง: "ประกาศ [หน่วยงาน]" → เรื่อง → ข้อความที่ประกาศหรือชี้แจง → "จึงประกาศมาเพื่อทราบโดยทั่วกัน" → "ประกาศ ณ วันที่ ..." → ลงชื่อ ตำแหน่ง หัวหน้าส่วนราชการต้องลงลายมือชื่อ

## หนังสือประทับตรา
ใช้เฉพาะ 6 กรณีไม่สำคัญ: ขอรายละเอียดเพิ่มเติม, ส่งสำเนาหนังสือ, ตอบรับทราบที่ไม่เกี่ยวกับเรื่องสำคัญหรือการเงิน, แจ้งผลงานที่ดำเนินการแล้ว, เตือนเรื่องค้าง, เรื่องที่หัวหน้าส่วนราชการระดับกรมขึ้นไปสั่งให้ใช้ ยังไม่มีรูปแบบส่งออกใน ราชการนี้ ให้ร่างเป็นหนังสือภายนอกและบอกผู้ใช้
