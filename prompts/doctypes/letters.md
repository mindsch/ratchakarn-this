# ชนิดเอกสาร: หนังสือภายนอกและสูตรตามวัตถุประสงค์

หนังสือภายนอก = หนังสือติดต่อราชการแบบพิธี ใช้กระดาษตราครุฑ ระหว่างส่วนราชการ หรือส่วนราชการกับหน่วยงานอื่น/บุคคลภายนอก ใช้ชนิด `หนังสือภายนอก`

## สูตรตามวัตถุประสงค์
**นำส่ง**: ภาคเหตุ (ตาม/ด้วย... ) → แจ้งว่าส่งอะไรไป จำนวนเท่าใด → ต้องการให้ผู้รับทำอย่างไรกับสิ่งที่ส่ง → "จึงเรียนมาเพื่อโปรดทราบ" หรือ "...โปรดพิจารณา"

**สอบถามรายละเอียด**: วัตถุประสงค์ชัดเจน → ต้องการรายละเอียดอะไร → ทำไมจึงจำเป็น → ถามเป็นข้อๆ ทีละประเด็น → "จึงเรียนมาเพื่อขอทราบว่า..."

**ตอบข้อสอบถาม**: ตอบครบทุกประเด็น → ส่วนที่ให้ไม่ได้ให้แสดงความเสียใจและแนะนำแหล่งอื่น → แสดงไมตรีพร้อมให้ข้อมูลเพิ่ม

**เชิญ** (วิทยากร กรรมการ ประชุม): แจ้งสาเหตุและวัตถุประสงค์ → ให้ความสำคัญผู้ถูกเชิญ → ชี้ว่าคุ้มค่ากับเวลาที่เสียไป → รายละเอียด ทำอะไร ที่ไหน เมื่อใด → แสดงความหวังและขอบคุณ → "จึงเรียนมาเพื่อขอเรียนเชิญ... และขอขอบคุณมา ณ โอกาสนี้"

**ขอร้อง / ขออนุมัติ / ขออนุญาต**: อ้างเหตุผลความจำเป็น → "ขอได้โปรด..." ให้ดำเนินการ → ขอบคุณในความอนุเคราะห์ ("จะขอบคุณยิ่ง")

**ขอความร่วมมือ** (สูตร ครวญ-ออด-มัด): ครวญ = แจ้งสาเหตุและเหตุผลชัดเจน; ออด = ชี้ความสำคัญของผู้รับหรือประโยชน์ที่จะได้; มัด = ขอร้องและตั้งความหวังว่าจะได้รับความร่วมมือ ขอบคุณล่วงหน้า และขอให้แจ้งผล (ถ้าต้องการ)

**ขอความช่วยเหลือ** (ผู้รับไม่มีหน้าที่เกี่ยวข้อง เช่น สมาคม มูลนิธิ เอกชน): ครวญ = ความจำเป็นและความต้องการ; ยอ = ยกย่องคุณธรรมของผู้รับ; ล่อ = ผลน่าภูมิใจที่เขาจะได้รับ; ออด = ขอความกรุณา; มัด = ตั้งความหวังและขอบคุณล่วงหน้า

**ขอบคุณ**: อ้างถึงความช่วยเหลือที่ได้รับอย่างถูกต้องและคุณค่าของมัน → ขอบคุณอย่างจริงใจ (อนุโมทนาหรืออวยพรเมื่อเหมาะสม) → ใช้ถ้อยคำเหมาะกับระดับบุญคุณและความสัมพันธ์

**ปฏิเสธ**: ขอบคุณ/ชื่นชม → เหตุผลชัดเจนก่อนปฏิเสธ (ไม่ปฏิเสธทันทีที่เริ่ม) → ปฏิเสธนุ่มนวล "ขออภัยที่ไม่อาจ..." → ให้ความหวังโอกาสหน้า ข้อยกเว้น: คำขอตามกฎหมายที่ต้องปฏิเสธตามกฎหมาย ให้เขียนตรงๆ ไม่ต้องขออภัย

**ตักเตือน / ตำหนิ**: เปลี่ยนเข็ม (ไม่ว่าตรงๆ แต่พูดว่าคนอื่นอาจตำหนิ) เบนเป้า (กำชับให้ผู้รับกำชับเจ้าหน้าที่) แสดงความเสียใจแทนความโกรธ → "จึงเรียนมาเพื่อโปรดกำชับ... มิให้เกิดกรณีเช่นนี้ขึ้นอีก"

**ติดตาม / เตือนเรื่องค้าง**: อ้างหนังสือเดิมและวันที่ → ระบุว่าเวลาล่วงเลยมานานแล้วยังไม่ได้รับ → ขอให้ดำเนินการภายในกำหนด → "จึงขอเรียนเตือนมาเพื่อโปรดดำเนินการ..."

**ร้องเรียน/ร้องทุกข์ จากประชาชน**: เล่าข้อเท็จจริงตามลำดับเวลา (ใคร ทำอะไร ที่ไหน เมื่อไร) → ผลกระทบ → สิ่งที่ขอให้ตรวจสอบหรือแก้ไข → ช่องทางติดต่อกลับ → แนบหลักฐาน ใช้น้ำเสียงสุภาพ ไม่ใช้อารมณ์ ใช้ชนิด `คำร้อง` หรือ `หนังสือภายนอก`
